# computer_construction_site
ITALIAN:<br>
Questo è un progetto scolastico di Educazione Civica dedicato alla struttura del PC, al funzionamento interno dei suoi componenti e al loro impatto sull'ambiente. Il progetto è stato realizzato a scopo educativo.
Struttura del progetto — il progetto è suddiviso in più file HTML e cartella con tutti immagini neccesarie, ognuno dei quali è dedicato a una specifica sezione informativa.<br>
ENGLISH:<br>
This is a school project for Civic Education (Educazione Civica) focused on the structure of a PC, the internal functioning of its components, and their environmental impact. The project was created for educational purposes.
Project structure — the project is divided into several HTML files and a folder containing all the necessary images, with each HTML file dedicated to a specific informational section.
